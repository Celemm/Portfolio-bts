Pokémon — Jeu de combat en terminal

Java POO Héritage Enum Terminal
Contexte

Jeu Pokémon backend développé entièrement en Java et jouable dans le terminal. Le joueur crée son Pokémon en choisissant son type, son nom et ses stats, puis le fait combattre contre un adversaire. Le projet met en pratique l'héritage, les enums et le polymorphisme en Java.

Fonctionnement

1. Création du Pokémon

Le joueur choisit parmi 4 types disponibles (Eau, Feu, Plante, Électrique), saisit un nom et les statistiques de base : vie, puissance, attaque. Chaque type instancie la sous-classe correspondante.

2. Système de combat

Le Pokémon du joueur affronte un adversaire généré automatiquement. Les dégâts infligés tiennent compte du type — certains types sont super-efficaces contre d'autres, comme dans le jeu original.

3. Affichage des résultats

Le terminal affiche le déroulement du combat tour par tour, les points de vie restants et le vainqueur final.

Architecture

Héritage et types

  • Pokemon — classe parente avec attributs communs : vie, puissance, nom, atk, type
  • PokemonEau — hérite de Pokemon, bonus contre Feu
  • PokemonFeu — hérite de Pokemon, bonus contre Plante
  • PokemonPlante — hérite de Pokemon, bonus contre Eau
  • PokemonElectric — hérite de Pokemon, bonus contre Eau
  • TypePokemon — enum des 4 types disponibles
  • Application — classe principale, menu et logique de combat

Concepts clés

  • Enum TypePokemon pour typer les instances
  • Polymorphisme pour le calcul des dégâts selon le type

  • Logique de combat avec gestion des points de vie

ITIC Companion — Application de gestion étudiante

Java XML Android Studio Figma Stage 1ère année
📂 Code source
Contexte

Stage de première année réalisé à l'ITIC Paris durant l'été 2025. L'objectif était de concevoir et développer une application mobile Android de gestion pour les étudiants de l'école — un équivalent de Pronote pensé pour l'ITIC, avec emploi du temps, notifications, système de classement gamifié et badge numérique d'accès à l'établissement.

Déroulement
du stage

1. Cahier des besoins

Réception par mail d'un cahier des charges précisant les attentes en termes de design, la liste des fonctionnalités principales et une palette de couleurs violettes/bleues à respecter.

2. Conception

Réalisation d'un diagramme de cas d'utilisation avec Lucidchart, puis modélisation des données avec Mocodo (MCD, MLD, MPD). Maquettage basse-fidélité avec Pencil Project avant de passer aux maquettes fonctionnelles haute-fidélité sur Figma, mises à jour itérativement selon les retours des maîtres de stage.

3. Développement

Développement de l'application en Java / XML sous Android Studio. Tests effectués sur un téléphone physique fourni par l'école. Livraison finale avec liste documentée des fonctionnalités implémentées.

Fonctionnalités

Écran d'accueil

  • Affichage personnalisé — Bonjour [prénom]
  • Discipline en cours avec horaire, professeur et salle
  • Classement BTS SIO 2 avec rang de l'étudiant
  • Fil de notifications (devoirs, notes, événements)

Badge numérique

  • QR Code unique servant de badge d'accès à l'établissement
  • Remplacement de la carte physique étudiant

Carte de rang gamifiée

  • Carte style Star Wars affichant le pseudo, le rang, les points et les absences
  • Système de classement global entre étudiants
  • Titres évolutifs selon les performances (Maître, Codemaster…)

Profil étudiant

  • Informations personnelles, date d'inscription
  • Mode sombre, langue, changement de mot de passe
  • Déconnexion et conditions d'utilisation

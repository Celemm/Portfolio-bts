Skystorm — Réplique Twitter en Laravel

Laravel 12 PHP MySQL Scolaire
📂 Code source
Contexte

SkyStorm est une réplique allégée de Twitter/X développée en Laravel 12 dans un contexte pédagogique pour la préparation à l'épreuve E6 du BTS SIO option SLAM. Le projet est construit en direct avec la classe afin d'illustrer un cycle complet de développement : conception, modélisation, implémentation et déploiement.

Ressources
fournies
  • Framework Laravel 12 — structure MVC, routing, Eloquent ORM
  • Documentation — Spécifications techniques et fonctionnelles
  • Base de données — Modélisation relationnelle MySQL
Réalisations

1. Authentification utilisateurs

Inscription, connexion et gestion de sessions avec Laravel Breeze. Chaque utilisateur dispose d'un profil public et d'un fil d'actualité.

2. Publication et interaction

  • Posts — création, suppression et affichage chronologique
  • Likes & Retweets — interactions sociales en temps réel
  • Abonnements — système de followers / following

3. Architecture MVC Laravel

Séparation claire entre les couches Contrôleur, Modèle et Vue (Blade). Utilisation d'Eloquent pour les relations entre entités.

Technologies

PHP / Laravel

Framework MVC pour la logique applicative et le routage.

MySQL

Base de données relationnelle pour la persistance des données.

JavaScript

Interactions dynamiques côté client.

Défis relevés
  • Prise en main rapide de Laravel 12 et de ses conventions
  • Modélisation des relations many-to-many (followers, likes)
  • Gestion des migrations et des seeders
  • Déploiement et configuration de l'environnement
